# HZ 9 Tool

Some 'Node.js' tool library.

## Introduction

`@hz-9/tool` is a monorepo that provides multiple Node.js tool libraries and utilities, managed with [Nx](https://nx.dev/) and [pnpm](https://pnpm.io/).

## Packages

| Package | Description |
|---------|-------------|
| [@hz-9/algorithm](./guide/algorithm/) | A JavaScript algorithm base class library |
| [@hz-9/docs-build](./guide/docs-build/) | A tool for generating vuepress-theme-hope documentation site from markdown files |

## Quick Start

```bash
# Install dependencies
pnpm install

# Build all packages
pnpm build

# Test all packages
pnpm test

# Lint all packages
pnpm lint
```
