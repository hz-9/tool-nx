- **Monorepo 编排**：采用 `pnpm workspace` 管理子包依赖，通过 `nx.json` 定义全局任务依赖图（如 `build` 依赖上游构建，`api-report` 依赖本地构建），实现增量构建与缓存优化。
- **标准化发布流**：集成 `changesets` 进行版本管理与变更日志生成，并通过 `scripts/release.sh` 自动化执行版本提升、Git 标签创建及锁文件同步。
- **文档与代码联动**：根目录 `docs-build.config.json` 作为中央配置，驱动 `docs_build` 模块将各子包（如 `algorithm`）生成的 API Markdown 文档自动映射为 VuePress 站点的导航与侧边栏结构，实现代码变更到文档更新的自动化闭环。
