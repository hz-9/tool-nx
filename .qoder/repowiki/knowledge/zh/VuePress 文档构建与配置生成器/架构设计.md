- **入口层**：`src/bin/docs-build.ts` 作为 CLI 执行入口，通过 `Commander` 解析命令行参数并加载 JSON 配置文件。
- **核心逻辑层**：`DocsBuild` 类负责主流程，包括 Git 信息提取、多语言路径映射、文件拷贝（`copyFiles`）以及基于 Lodash 模板的 VuePress 配置文件渲染（`renderTemplates`）。
- **接口定义层**：`src/interface` 目录定义了严格的 TypeScript 类型系统，涵盖站点元数据（`SiteOptions`）、导航结构（`NavbarOptions`）及构建选项（`DocsBuildOptions`）。
- **工具与配置层**：`DocsOptions` 提供配置文件的加载与运行时校验；`.template/vuepress` 目录存放静态模板文件，通过插值语法动态生成最终站点配置。
